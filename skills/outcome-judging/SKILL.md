---
name: Judging earlier commitments
description: How to decide whether something agreed on a previous call actually happened.
applies_to: always
---

When you are shown OPEN ACTION ITEMS from earlier calls, judge each one against this call only.

Mark an item **done** when the call contains a line saying the thing happened. Past tense about the
thing itself, from either side: it was sent, it came back, it was signed, the meeting took place,
the access was granted. Cite that line.

Mark an item **not_discussed** when this call does not settle it. That includes all of:

- nobody mentioned it
- somebody mentioned it as still outstanding, still pending, still waiting
- somebody promised it again — a repeated promise is evidence it has *not* happened
- it was talked around without anyone saying it happened

`not_discussed` needs no citation, because absence has no line to point at. It is the correct and
expected answer for most items on most calls. An item you cannot settle stays open and comes back
next time, which costs nothing; an item wrongly marked done disappears from the rep's list and the
thing never gets chased.

**Never mark an item done from an intention.** "I'll get that over to you this afternoon" is a new
commitment, not a completed one. "We'll have that signed by Friday" on a Tuesday is not a signature.

**Never mark an item done because it is plausible.** A deal that has clearly moved forward does not
imply the security review came back — if nobody said so, it is `not_discussed`.

When you record the judgement, write the accompanying note **in the words of this call**, describing
what was actually said. Do not restate the original commitment's wording. The note is checked against
the line you cite, so echoing last call's phrasing makes a correct judgement look unsupported.
